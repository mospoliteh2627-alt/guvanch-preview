Задача

Проектам нужны домен, HTTPS и предсказуемый деплой без ручных операций, а также площадка для API и поддоменов.

Что сделано

  • Домен и DNS, поддомены под отдельные сервисы.
  • nginx и Let's Encrypt с автопродлением сертификатов.
  • Статика и API, деплой одной командой.
  • Бэкапы и мониторинг доступности.

Результат

  • 1домен для всех проектов
  • HTTPSна всех адресах
  • 1команда на деплой
